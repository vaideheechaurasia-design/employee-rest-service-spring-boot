# Employee REST Service using Spring Boot

A simple RESTful web service developed using **Java and Spring Boot** to retrieve employee information through a REST API.

## 🚀 Features

- Built using Java and Spring Boot
- RESTful API implementation
- Retrieve employee information using HTTP GET
- Returns employee data in JSON format
- Contains sample employee records
- Simple and beginner-friendly project structure

## 🛠️ Technologies Used

- Java
- Spring Boot
- REST API
- Maven
- JSON
